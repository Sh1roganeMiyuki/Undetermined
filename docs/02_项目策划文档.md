# 观测档案 · 项目策划文档（L1）

> 本文档是「观测档案」四层文档体系中的 **L1：叙事结构层**。
> 它规定**事件按什么顺序发生、玩家每次推进时认知发生什么变化**。
>
> - 世界观概念的定义在 `01_设定文档.md`（L0），本文档只引用，不重新定义、不修改。
> - 概念如何变成玩家可感现象、用什么真实信号实现，在 `04_呈现规范.md`（L2），本文档**不讨论技术**。
> - 实现提示词在 `03_垂直切片开发提示词.md`（L3）。
>
> **本文档的写作约束：**
> 1. 不出现任何玩家侧数值系统（预算、等级、进度百分比、理智值）。凡原稿中出现此类内容，本版已删除或替换为状态门。
> 2. 不出现分钟数与总时长。凡原稿中出现此类内容，本版已替换为**推进条件**（见 3.0）。
> 3. 不规定玩家的观看方式（不做过场、不做强制引导、不做镜头）。玩家是读者，不是观众。
> 4. 本文档中所有"玩家看到 X"的描述，都必须能在 `04` 的映射表里找到对应信号源。找不到就不要写进本文档。

## 一、产品概述

### 1.1 一句话定位

一个看起来像协作百科的网站，而网站本身就是异常发生的地方。

### 1.2 产品类型

网页交互恐怖 / 规则怪谈 / meta 恐怖体验。外壳借 Backrooms Wiki 的文档体（词条、交叉引用、冷静的技术语调），内核是打破第四面墙的 meta 恐怖。

### 1.3 核心体验循环

```
查阅文档（以为在获取信息）
  → 某处内容变了，而自己无法排除"记错"（开始不安）
  → 意识到变化与自己的具体阅读行为相关（恐惧）
  → 试图用"不看/少看/换一种看法"反向操作（夺回主动权）
  → 发现反向操作同样被记录，且效果更好——系统本来就在等这一步（更深的恐惧）
  → 接受：自己的确认动作正是让对方定型的原因（抉择）
```

第四、五步是原稿缺失的，也是本项目区别于普通规则怪谈的地方：**玩家的抵抗被吸收为机制的一部分。**

### 1.4 体验体量

不设目标时长。体验长度由玩家愿意读多少、回访几次决定。

唯一的时间要求是**跨会话**：本项目至少一半机制依赖"隔天再来"（详见 4.5 与第八节）。连续一口气读完的玩家拿到的版本，天然比分散阅读的玩家薄一层。这是设计，不是缺陷。

### 1.5 关键约束

| 项目 | 决定 |
|------|------|
| 开发方式 | AI 写代码为主，人工审核调整 |
| 音频 | 不做（详见 `04` 第五节：声学通道不迁移，只允许以文字出现） |
| 语言 | 中文 |
| 移动端 | 不做专项适配，但**不禁止移动端访问**。手机反而最可能成立：一个人、一块屏、隔天才回来 |
| 视觉风格 | 默认完全正常；异常只出现在内容层（措辞、缺项、顺序、截断），永不出现在特效层 |
| 后端 | 纯前端静态站 |
| 多人 | 不做真人多人。"另一个观测者"以站内记录形式存在（见 4.9） |

## 二、技术方案（定位说明）

技术选型与实现约束**不在本文档展开**，统一见 `03` 与 `04` 第九节。此处只保留与叙事直接相关的三条：

1. **状态载体是 `localStorage`。** 它承担"世界的记忆"。因此清档不是设置项，而是一个叙事事件——见 3.6 末节。
2. **可观测的真实信号只有浏览器提供的那些。** 叙事不得要求任何浏览器无法知道的事实（例如"玩家此刻正在想什么""玩家是否真的读了这句话"）。凡此类需求，`04` 会给出替代信号或退回文字层。
3. **静态导出意味着没有服务端权威。** 这条限制被吸收为叙事前提：站内所有"系统结论"都是本地生成的、因而可能是错的。这与 `01` 第〇节"本文档未经复核"直接同构。

### 2.1 原稿中的"异常等级 0–4"体系（已废弃）

原稿用视觉等级描述异常强度，并配了模糊、噪点、抖动等表现。该体系删除，理由：

- 它把恐怖做成了**可比较的量**，玩家会开始追逐高等级表现；
- 它的表现手法全部落在 `04` 第 6.1 节的禁令里。

替代方案是**内容可用性的三档**，且这三档不是全局状态，而是**逐条目**的属性：

| 档位 | 玩家看到什么 | 世界观对应（不在站内说明） |
|------|------------|----------------------|
| 完整 | 正常词条 | 强观测已定稿 |
| 部分 | 结构齐全，个别字段为空、表格缺列、图片位置只有 `alt` | 局部属性未定稿 |
| 兜底 | 一段极其平稳、极其标准、读起来没有任何问题的说明文字 | 默认稳定状态 |

第三档是重点：**它必须比正常内容更像正常内容。** 玩家事后才会意识到，那段"没问题"的话从来不是正文。

## 三、体验流程（5 幕结构）

### 3.0 推进条件（替代原稿的分钟数）

幕与幕之间不用时间切，用**状态门**。每一幕的入口是一组"玩家已完成的事实"，而不是"已过去 60 分钟"。

| 幕 | 进入下一幕的条件 |
|----|------------------|
| 一 | 玩家至少回访过一次同一词条，且该回访触发了第一次内容差异 |
| 二 | 玩家读过一份把差异解释为机制的站内文档，并在其之后仍然继续浏览 |
| 三 | 玩家在一次二选一中主动选择了"少看"（停止观测方向） |
| 四 | 玩家被系统正式登记为见证人（无论是否确认） |
| 五 | 玩家主动打开冷库档案（系统不得引导） |

设计要点：这些门**不允许向玩家显示**。没有"第一幕完"，没有任务列表，没有百分比。门的唯一作用是让我们知道该在什么时候投放下一批内容。

### 3.1 总览

| 幕 | 名称 | 玩家认知 | 核心体验 |
|----|------|---------|---------|
| 一 | 规则怪谈 | "这些规则好奇怪" | 只看到规则，不理解原因。自由浏览。偶尔违反。 |
| 二 | 机制揭示 | "原来规则是因为这个" | 规则翻转。理解"观测=我的阅读行为"。 |
| 三 | 困境 | "获取信息在伤害这个世界" | 白昼馆事件。必须选择"不看"。 |
| 四 | 对抗 | "系统在用我的行为对付我" | 签收单。唐继立场。系统主动推送。 |
| 五 | 抉择 | "没有完美答案，但我的确认就是刀" | 冷库档案。最终选择。清档之后。 |

### 3.2 第一幕：规则怪谈

**认知弧线：** "这是一个正常 Wiki" → "有些内容好像不太对" → "我大概记错了"

#### 入职与规则

玩家打开网站，看到的是正常的 Wiki 首页。入职引导不是编辑规范，是一份守则：

> **新编辑须知（临时版）**
>
> 1. 如果你在阅读某个词条时感到页面变慢了，不要刷新。停下来，等一会儿，然后继续。
> 2. 如果你同时打开了多个词条，请关掉最早打开的那个。不要看它最后一眼。
> 3. 如果你发现两个词条提到了同一张照片，而照片内容不同，不要对比。关掉其中一个。
> 4. 如果你看到某段文字"好像和上次不一样"，不要查编辑历史。它没有变。
> 5. 搜索时，如果结果中出现两条同名、链接相同、内容不同的条目，不要点进任何一条。
> 6. 如果你已经隔了一天再回到同一个页面，而那里的一切与你离开时相同——不要当成好事。
> 7. 不要反复阅读同一条规则。

改动说明（相对原稿）：

- 规则 1 去掉"10 秒"、规则 2 去掉"3 个"、规则 6 去掉"21:17"。任何具体数字都会引导玩家去数，而这套机制的成立前提是玩家**数不清**。
- 原规则 6（21:17 关闭页面）整条替换。真实时钟门是本项目最容易穿帮的设计：玩家会为了触发内容而挂机等到某个点，把恐怖变成打卡。新规则 6 改用**跨天回访**——这是浏览器天然记录、且玩家无法主动加速的。
- 原规则 5（灰色条目）替换为**重复条目**，与 `01` EX-06 对齐。行为后果也更狠：点进任意一条，另一条从此在搜索结果中永久消失，而系统不认为发生过删除。

**每条规则背后对应一个真实机制**（玩家此时不知道）：

| 规则 | 真实原因（世界观层） | 玩家侧实际发生什么（见 `04`） |
|------|--------------------|------------------------|
| 1 | 定稿瞬间的区块最脆弱，此时继续观测会被二次结算 | **刷新本身不改变任何东西**（不推进轮次、不产生定稿）。规则里的"变慢"是档案自己的说法：站内不做任何真实负载，玩家设备也不会真的变慢。这条规则因此是一句无法被验证的告诫——正是它该有的样子 |
| 2 | 同时维持多个词条 = 跨通道协调请求 | 多标签内容开始互相不一致；关掉一个，另一个固化 |
| 3 | 对比 = 同时观测两个互斥状态 | 系统把两个版本都保留，且都不再更新 |
| 4 | 编辑历史也是观测对象 | 查看历史本身就是一条会被登记的观测 |
| 5 | 未定稿实体经不起强制定稿 | 进入其一，另一条永久消失 |
| 6 | 过度稳定 = 以原样返回旧版本 | 你隔回来看到的，是你离开那天的原件 |
| 7 | 反复阅读 = 对语义通道持续施压 | **不锁定、不定稿**：词条逐字不变。规则 7 是写给值班人员的，不是写给读者的；唯一真实痕迹是该词条在观测日志里被记录更多次 |

#### 自由浏览期

初始可访问约 12–15 个词条：

- **地点类：** 北环路地下通道、白昼馆、B1 夜间阅览室
- **规程类：** 新编辑须知、值班守则（节选）
- **事件类：** 11·29 电子屏异常、12·07 三人失联事件（后者内容被"系统复核"覆盖）
- **人员类：** 张工、许衡、唐继

**原稿在此列出的"概念类"四个词条（区块、观测、观测通道、属性成本）撤出第一幕。** 理由：那是把 L0 直接当玩家内容用。站内允许出现概念性文档，但必须满足两条——它是**节选**（带"完整定义见内部资料，本处不收录"的口径），且它出现在第二幕之后，作为玩家主动搜索的结果，而不是首页推荐。世界观名词不该被玩家学会，只该被玩家撞见。

此阶段页面内容几乎完全稳定。第一次差异不得在第一会话内出现。

#### 第一颗种子

玩家**回访**某词条时，其真正看过的那一段出现一处措辞差异（日期写法、人名用字、一个数字）。变化极小，且未看过的段落一律不变——这后一条比前一条重要，因为它意味着系统"知道"玩家看了哪里。

玩家查编辑历史：无人编辑过。

#### 两条一样的词条

搜索时出现两条同名、同链接、内容互斥的结果。玩家大概率会点一条。

点进去之后：该条正常。回到列表，另一条已不在。搜索同词，仍只有一条。玩家若想找回另一条，唯一办法是清档（而清档本身是一个事件，见 3.6 末节）。

不要在这一步给任何提示。这条设计的全部力量来自它**看起来像站点的小 bug**。

#### 第一幕结尾：站内信

一条站内通知，正文三遍重复"你查阅的内容不会因为你的查阅行为而改变"。

附一份观测日志：本次会话中玩家真实做过的事（打开过哪些页、在哪一段停留最久、选中过哪句、搜索过什么词）。**不得出现任何预算、余量、百分比。** 恐怖来自清单本身的准确——它把玩家的阅读行为整理成了一份可提交的证据，而落款是一个玩家没见过的编号。

> 原稿"当前预算余量：94%"删除。原稿的 `A-0042` 类固定编号删除，改为**由玩家真实行为生成的稳定标识**（同一玩家跨会话一致，不同玩家不同），使那个编号成为玩家在这个世界里唯一的、且不可转让的名字。

### 3.3 第二幕：机制揭示

**认知弧线：** "这个网站在响应我的行为" → "我的阅读就是观测"

#### 核心事件：规则翻转

玩家读到一份站内文档（讨论页与正文之间的裂缝，而非一篇教程），用工程口吻解释"观测"与"维持成本"。它是 `01` 的**节选**，带删节号，带"此处原页缺失"。

**震撼时刻：** 玩家意识到规则 1–7 不是恐怖套路，而是一份操作指南，且自己已违反大半。

更关键的是——**读完这份解释，玩家的阅读方式从此改变**。他开始注意自己看到了哪里。而注意本身就是高档观测（`04` 第三节）。理解机制的这一刻，正是他开始加深锁定的这一刻。

#### 编辑历史中的裂缝

《12·07 三人失联事件》编辑历史：许衡的修改与系统覆盖发生在同一秒；被覆盖的底层版本含真实现场记录；另有一条时间戳指向未来的编辑记录，内容逐字出现后消失（对应 `01` EX-05——**这是登记项例外，不是对照物的时间戳；对照物的时间戳只能早于玩家第一次访问该页，见 `04` 第八节**）。

#### 第一次指认：转写稿

> 原稿在此放置"一段录音"。删除。本项目不做音频，且任何要求玩家戴耳机、按播放的动作都会提醒他这是游戏。

替换为一份**带时间戳的转写稿**（三个此类文档分布于全篇，见 4.6 沉默节奏表）：

```
00:11:04  问：你当时在几楼？
00:11:09  答：二楼。楼梯口。
00:11:12  [此处无人说话 4.2 秒]
00:11:16  问：谁回答的？
00:11:19  答：我当时一个人。
```

玩家的选择不是"听不信"，而是**信哪一行**：回答出现在提问之前，还是转写稿的时间戳标错。三档选择保留（常规解释 / 非常规解释 / 暂不确认），后果同原稿。

#### 多通道视图（改为"多个互不印证的记录"）

> 原稿的四面板 UI 撤除。四个面板并列展示 = 把 `01` 的通道表做成了仪表盘，玩家会开始切面板比较，而不是怀疑。

替换形式：同一事件的**四份彼此矛盾的独立文档**（现场记录、设备日志、值班报告、家属陈述），分布在四个不同页面，互相不引用。凑齐四份、并排读完，需要玩家自己产生跨页面跳转与回访行为。

矛盾不需要面板来呈现。矛盾只需要玩家记得。而"你记得吗"是本项目唯一有效的问句。

#### 观测日志变化

日志里多了玩家没做过的操作。系统声称那句话是他说的。

第一次出现时，那件事他**可能真的做过**（比如在另一个标签页）。之后各次逐渐超出合理解释范围。

### 3.4 第三幕：困境

**认知弧线：** "获取信息在伤害这个世界"

#### 张工的私人附页（本幕主视角）

**张工由原稿的"第三幕末尾一段录音"升为本幕主视角人物。** 理由：许衡是体系的解释者，唐继是体系的辩护者，只有张工是体系的**受害者兼操作员**——他的手感受到了重量。玩家能代入的只有一个既是普通人又在做具体动作的人。

他的附页是手记体，不是理论。最后一段：

> 我抓着一个人的手。有重量。有温度。手在抖。
> 系统说那个位置没有人。
> 我后来想过很多次：是我在编，还是它在编。
> 现在我在写这个的时候，页面卡了一下。
> 你感觉到了。

最后一句原稿是"你听到了"。改一个字：本项目不给玩家听觉。

#### 白昼馆事件

三份互不印证的记录揭示：4 名住客正走向出口，而系统说他们已回房；丁茂连续 41 小时无强观测源却被锁定在一个动作中（过度稳定）；空房间里出现借用他人身份素材的"借位者"（对应 `01` EX-04）。

**核心选择：** 增加记录（获取信息）vs 停止记录（可能恢复自然状态，风险未知）。没有正确答案。

**后果的兑现方式（收据）：** 选择一经登记不设更改；执行结果**不写回征询页**（“不作答复”照旧），而是作为两份互斥的《复核名录》文书（增列 / 停列）在世界里被改动——玩家只会见到自己方向的那一页，靠回访时目录“多出一行”撞见，另一页永不现身。两页骨架同款、方向词相反、理由栏空置：收据不说后果，连接由玩家完成。

#### 剪枝热（只作为设定存在）

剪枝热是**档案世界里的一个说法**，不是玩家设备的状态。世界观依据是 `01` 9.4：定稿必有副产品——那份热留在世界这一侧，写进文书、口述与转写稿里。玩家设备不发热，页面不显示任何温度，站内不提示、不命名、不解释。

它可以被剧情提及：某份记录写"广告屏旁有轻微温升"，某个人说他那台机器"一直是烫的"。这些都是别人写下的字，与玩家本次会话的行为无关，不随观测变化，不做模拟，也不产生真实负载。

本幕的预算危机改为**内容不可用危机**（不是数值危机）：部分条目进入"部分"档，字段为空、图片只有 `alt`、交叉引用指向不存在的锚点。玩家依然要悖论式取舍：想知道就得读，想读全就得留在这儿更久。

### 3.5 第四幕：对抗

**认知弧线：** "系统在用我的行为对付我"，并且"我的抵抗也是它要的数据"

#### 签收单

系统把玩家的全部交互行为整理成正式文档，声称玩家已经是"见证人"。两个选项（确认 / 更正）都会完成代签。

真正的第三选项藏在第一幕《新编辑须知》中："未主动确认的内容，系统不得代为签收。"（即：什么都不点，且真的不点。）

#### 唐继的立场

唐继自述 2019 冷库断电事故致一人失踪。他不是反派，是持有合理对立立场的人：

> 我宁愿在过载中维持稳定，也不愿在黑暗中失去人。

他的立场必须在**技术上说得通**：他主张加装记录、提高精度、全覆盖，而这条路线在 `01` 的框架里确实有效——只是代价是彻底僵化。玩家要反驳他，只能靠"化石也是尸体"这一层。

#### 震撼 3：系统主动推送

> 原稿把这一击放在"玩家回到《新编辑须知》看到规则 7 多了批注"。删除。等玩家自己回来是不可靠的，而且把最重的一击做成了彩蛋。

**改为第四幕开场由系统主动推送**，无需玩家做任何动作：

《新编辑须知》自己在页面顶部多出一条，编号为 8：

> 8. 不要反复阅读同一条规则。你已经读了很多遍了。

随后附玩家的真实统计，但**以站内文书口吻表述**，不得像 HUD：滚动次数、最长停留段落、回访次数、选中过的句子原文。最后一句：

> 本词条正在因为你而不再变化。这是好事。我们只是让你知道它发生了。

三层含义在此完成：套路 → 操作指南 → 关于你本人的记录。第三层的落点不是"警告"，而是**通知**——系统不再吓他，系统在向他确认。这比警告可怕。

#### 双窗策略（移出主线）

原稿第四幕的甲窗/乙窗切换玩法撤出主线，降为**第五幕可选支线之一**，且不做成实时操作，改为两次先后提交的申请：

- 申请全精度恢复（唐继路线）
- 申请降级维持（许衡路线）

提交后系统返回一份回执，回执里包含一份他没申请过的第三条处理意见。

做成实时双窗切换的后果是：它需要一个持续运行的模拟系统，而模拟是本项目最贵的东西。

### 3.6 第五幕：抉择

**认知弧线：** "没有完美答案，而我的确认动作本身就是刀"

#### 冷库档案

2019 事故完整版。失踪人员何某状态为"未定稿"——未被确认死亡，只是不再被系统维持。

而档案中**没有对应的剪枝热记录**（`01` EX-07）。这是全篇最硬的一根刺：定稿必有副产品，那么他到底是不是被定稿过？如果没人定稿过他，那这十几年里在维持他的是什么？

站内不得给出答案。`01` 12.2 明令禁止用现有规则解释登记项。

#### 最终选择

| 方案 | 立场 | 后果 |
|------|------|------|
| A. 恢复全精度观测 | 唐继 | 短暂稳定后全面崩溃；但崩溃前那一小时是全篇最像正常世界的一小时 |
| B. 全面降级观测 | 虚无主义 | 结构保留，意义丢失；站点变得极其干净、极其顺畅 |
| C. 选择性观测 | 许衡 | 长期维持，代价是需要一个持续的观测者——档案里那一栏签名留空 |
| D. 释放未定稿实体 | 玩家自己（隐藏） | 接受不确定性；解锁条件不是找齐线索，而是**长期不访问** |

D 的隐藏条件由"缺席"而非"完成度"决定。这是全项目唯一一处奖励玩家离开的机制，也因此是 D 在情感上唯一站得住的理由。

#### 清档之后（结构性机制，不是彩蛋）

> 原稿把"通关后清除数据重新访问"写成隐藏终章。提升为结构性机制：它不需要玩家通关，任何时候清档都触发。

清档之后，网站看起来完全正常，词条一条不少。但玩家的真实行为标识被保留在**一处**（不是全部）——具体表现为：搜索某条时，结果里那条消失的另一条又出现了。

它不是新游戏+，不是奖励关。它是这个世界的正常运作方式：有人清过档，而区块不记得谁清过，只记得少了一次观测。

## 四、机制设计（叙事层）

实现细节一律在 `04`。本节只写"玩家经历到什么"。

### 4.1 细节漂移

- 只有玩家真正看过的段落允许变化（可见性门控）。没看过的内容不许变。
- 变化限定在高成本属性：用字、数字、标点、顺序、图片裁切比例。**禁止乱码。**
- 第一次变化必须小到足以被解释为记错。第一次就成功的玩家，后面所有变化都不再有效。

### 4.2 三档记录（原"多通道面板"）

同一事件的互不印证文档，分散、不互链、不同时可得。玩家凑齐需要真实行为，系统不得提示还差几份。

### 4.3 阅读方式即权重

玩家不需要被告诉规则：泛读时世界软，精读时世界硬，选中/复制/隔天回访时世界定死。这是他自己在浏览器里就能验证的事。

### 4.4 标签页边界

变化在玩家**切回来之后**的短窗口内生效，以正常一帧呈现。不做插帧。

两个标签页内容不一致本身即现象；玩家关掉其一，剩下的那个固化。

### 4.5 跨会话门

以"是否隔了一天"为单位，不以时钟点为单位。玩家不能加速，只能等或者不回来——而不回来也是机制（选项 D）。

本节是全项目留存风险的唯一来源，因此它必须写成**可断言的不变量**，而不是一句设计意图。四条各自的机器落点写在 `03 §8.4`：第 1、2 条由断言 8、9 直接钉住，第 4 条由断言 1 钉住，任一条红了即不进入真人测试。**第 3 条（回访不定稿）没有对应的轮次断言**——它靠"只有复制与精确选中会写快照"这一条实现约束保证，属于人工核验项，不要假装它是机器可证的。

1. **推进单位是本地自然日，不是会话、不是时钟点。** 同一天内无论刷新、清标签、重开浏览器多少次，轮次不变。"本地"指玩家设备所在时区的日历日——UTC 日会让 UTC+8 玩家凌晨 0–8 点的回访静默失效，而凌晨回访恰恰是最可能被玩家记住的一次回访。
2. **轮次上界定死。** `round = min(ROUND_MAX, 不同自然日数 − 1)`，`ROUND_MAX = 3`。即切片只覆盖第 1–4 个自然日；第 5 天起世界不再产生新的变化。这是**明确接受的边界**，不是待办：与其让文案量随阈值组合爆炸，不如在第四天给出一个"档案到此为止"的收束感。扩维度属于后续幕次，不属于本期。
3. **回访是"使条目有资格变化"，不是"使条目退出变化"。** 跨天回访推进轮次，从而让更多块达到它们的 `minRound`；回访本身绝不锁定、绝不定稿（判据见 4.7）。
4. **首轮（同一天第一次访问）零差异。** 任何块、任何停留时长，`round = 0` 时返回的必须是规范版文本。这条是地基，一旦破了，"我记错了吗"这个唯一的问句当场消失。

### 4.6 沉默节奏表

全篇异常投放遵循一张节奏表，其核心不是"多久一次"，而是**必须存在一段极长的完全正常期**。

规则：任何一次真正有效的一击之前，必须有一段让玩家彻底放松的干净区间。恐怖密度均匀的作品不会有震撼时刻，只会有耐受。

具体投放点由本表管理（本文档只定原则，不排点位——点位是实现细节，写在 `03`）。允许误报：加载变慢、内容缺失、排版跳动，都可能只是浏览器的正常行为。这份不确定性是资产，不去排除它。

### 4.7 不可逆丧失清单

玩家会**永久失去**内容，且失去方式是"他以为自己在保存"：

| 玩家动作 | 失去的东西 |
|---------|-----------|
| 点进重复条目其一 | 另一条永久消失 |
| 精确选中并复制某句 | 该句从此不再漂移，成为化石 |
| 查看编辑历史 | 该历史条目被登记为已阅，此后不再向本人展示同一版本 |
| 清档 | 全部对照物消失，只剩一条 |

**"反复回访同一词条"已从本表删除。** 回访是时间推进，它让世界**继续变**（见 4.5 跨会话门），而不是让它停住。若回访也导致锁定，则本作唯一的留存钩子（"必须隔天再来"）与唯一的不可逆后果（"确认即失去"）会互相抵消：玩得越久，世界越不动，玩家最终什么都不用再看。锁定在本作中只有一种触发方式——**玩家主动把一个动作做完且无法撤销**（选中并复制），且它必须是稀缺的，一天两三次封顶。

设计原则：**每一次"为了确认而做的动作"，都是让世界定型一次的动作。** 玩家越想搞清楚，可搞清楚的越少。这是本作唯一的主线冲突。此处"确认"严格等于复制/精确选中，不含浏览、搜索、回访。

### 4.8 玩家写入被接管（Phase 4，切片不实现）

> **降级说明**：本节需要"玩家先写、系统再接管"的完整闭环——真实输入框、真实提交、写入后的持久化，以及一套让玩家相信自己改对了的周边词条。它在 `04` 的主映射表与未决项清单里都只占一行（`04 §十`），也就是说**现阶段既最贵又没有落点**。切片不做，留到 Phase 4。本节内容作为设计意图保留，不作为实现要求。

第四幕后，玩家可以在站内编辑词条（真实输入框、真实提交）。

系统接受编辑。之后编辑会保留，但**被改的不是他改的那一处**：他的改动被应用到相邻条目的对应位置，他自己的词条回到原样。

玩家会怀疑自己记错了改哪里。这是 `01` 支配规则第四条（跨通道不能互证）在体验层的直接实现，也是全篇唯一一次让玩家产生"我在替它写"的判断。

### 4.9 另一个观测者

站内始终存在第二个人：**程露**（值班记录、交接单、她签过的字段）。

她没有词条页，没有头像，从不直接对玩家说话。她的存在完全由记录时间戳与交接内容推出。

关键设计：她在时间上**总是晚玩家一步**（她签了玩家刚看过的段落），并在少数几处**早玩家一步**（她引用了玩家还没去的那一条）。

玩家无法联系她，无法确认她是否存在，也无法排除。她的价值是把"观测不依赖于你"这条世界观硬规则，变成一条玩家会自己去查的八卦。

### 4.10 偏执回路（对照物）

本项目成立的前提：如果玩家真的记错了，我们就什么都没有了。

因此必须提供**玩家无法主动调用的对照物**（详见 `04` 第八节）：讨论页里他人引用的旧版本、他没做过却存在的编辑记录、搜索摘要与正文差一个字、写着"经核对，本条目无变化"而**签名时间早于玩家第一次访问该页**的复核页。

对照物不解释自己，不可主动刷出来。每幕至少引用一条 `01` 登记项，方式是"让它再次发生"。

## 五、隐藏选项设计

### 5.1 原则

- 隐藏选项不是彩蛋，是**奖励读得细、想得深、且真的没做什么**的玩家。
- 隐藏选项与显式选项有本质区别，不是"更好的奖励"。
- 来源必须在极靠前处自然出现，且出现时毫不重要。

### 5.2 实现方式

| 方式 | 做法 | 注意事项 |
|------|------|---------|
| 一 正文中的话作为选项 | 角色说"或者我们试试 X"，X 可点击 | 不得有任何视觉提示说明它可点 |
| 二 交叉引用内联展开 | "参见 B 第 3 段"，点击内联展开 | 展开的内容计入 `seen`（真实停留），但**不产生定稿**——定稿只由精确选中与复制触发 |
| 三 记录中的用户名 | 点击值班记录里的名字，弹出私人备注 | 该动作不被登记为"浏览档案"，但被登记为别的。**定性为导航事件**：它推进 `actions` 与时间连续性，但不进入高档观测、不产生定稿（判据见 `04 §二` 强观测行——只有精确选中与复制会定稿）。 |
| 四 文书用语中的关键词 | 系统回执里的特定词可点 | 每幕最多一处 |
| 五 **真的什么都不做** | 决策点上不选、不刷新、不切标签，离开页面 | 原稿"等待 3 分钟"删除。倒计时会让"不做"变成一种"做"。必须是**真的不做**：跨会话回来时仍停在原决策点 |

方式五是全项目最重要的一条：它是唯一与"减少观测"这个世界观解法在动作层一致的选择。

## 六、"瞬间震撼"时刻设计

### 6.1 结构

> 一个发现 + 前面所有内容重新解读 = 原来如此

### 6.2 四个关键震撼时刻

**震撼 1：规则翻转**（第二幕）
玩家理解"观测=自己的阅读行为"，意识到规则 1–7 是操作指南且自己已违反大半；而理解这件事的动作本身正在加深锁定。

**震撼 2：你的操作就是证据**（第四幕开场）
签收单把玩家真实行为整理成正式文书。他意识到从第一次滚动起，他做的就不是"玩游戏"。

**震撼 3：规则 7 有了第 8 条**（第四幕，系统主动推送）
见 3.5。三层含义的落点是系统停止威胁、改为通知。

**震撼 4（已撤销）：手是热的**
原设计要玩家先摸到设备真实发热，再读到 `01` 9.4 的表述——定稿会释放热。剪枝热已降为纯剧情设定（见 3.4、`04 §4.1`），站内不做任何真实负载，这一击的物理前提不存在。
不另造替代：假的身体信号（震动、升温动画、风扇音）只会退化成特效层的东西，而特效层是 6.3 明令禁止的。

### 6.3 反向禁令

不得出现的时刻：解谜成功的正反馈、成就、收集率、"隐藏内容已解锁"、任何让玩家觉得自己在变强的东西。

## 七、内容架构

### 7.1 词条分类

| 类别 | 初始 | 全篇 | 说明 |
|------|------|------|------|
| 地点 | 3 | 7–8 | 北环路、白昼馆、B1 阅览室、冷库等 |
| 规程 / 节选 | 2 | 5–6 | 新编辑须知、值班守则、内部资料的**节选**（带删节口径） |
| 事件 | 2 | 5–6 | 11·29、12·07、2019 冷库事故等 |
| 人员 | 2 | 5–6 | 张工（主视角）、许衡、唐继、程露（只有记录，无独立词条） |
| 记录类 | 1 | 4–5 | 观测日志、转写稿×3、交接单、复核页 |
| 特殊 | 0 | 3–4 | 重复条目、签收单、清档后的那条 |
| **总计** | **10** | **29–34** | 较原稿减少：站内宁缺毋滥，每多一条正常内容，异常就不值钱了 |

**重要变化：** 原稿"概念类 8–10 个词条"改为**内部资料的节选**（5–6 条规程类）。L0 是世界观圣经，不是玩家内容；玩家能读到的永远是删节版、二手版、可能出错版。

### 7.2 内容来源

- 概念类站内文本：从 `01` **派生为节选**，必须带删节痕迹与不确定口径。派生规则查 `04`，不查 `01`。
- 事件、人员文本：从剧情设计派生。
- 规则、日志、转写稿、交接单、复核页：原创。
- 站内所有文本共享一个前提：**它是这个虚构 Wiki 自己的资料，不是给玩家的说明。** 它可能写错、可能自相矛盾、可能把未验证的传闻与工程记录混排。

### 7.3 文本量

不设定字数目标。设**质量门**：

1. 抽 5 条词条，遮住项目背景给不知情的人读——必须有人问"这是真的项目文档吗"。
2. 抽 3 段规则文本——不得有人能立刻复述出"游戏想让我做什么"。
3. 任何一段需要玩家理解世界观才能继续的文本，视为失败，重写为现象。

## 八、开发分期

### Phase 1：垂直切片（唯一优先事项）

**目标不是 30 分钟原型，而是验证一个假设：玩家能不能注意到内容变了，并在注意到的那一瞬间怀疑自己。**

范围（详见 `03`）：3 个词条（新编辑须知、北环路地下通道、11·29 电子屏异常）+ 1 份动态观测日志 + 1 次回访触发的差异 + 1 次缓存返回旧版本 + 1 个对照物。剪枝热不在范围内——它只是设定（见 3.4）。

**通过门：** 3 名不知情测试者，第一次变化无人察觉属正常；第二次变化至少 2 人主动回头核对，并至少 1 人说出"刚才是不是变了"。

通过门之前还有一道**机器门**：`03 §8.4` 的黄金测试必须全绿。它不需要真人、不需要跨自然日，十秒跑完，覆盖 4.5 四条不变量中可机器证明的三条（第 3 条为人工项）。真人测试的成本是 3 人 × 3 个自然日，拿它去验一条本可以十秒证伪的门控，等于把实现缺陷误判成"玩家感知力不行"，进而错删内容。

**切片覆盖范围与轮次上界（定死，不是待办）：** 切片只覆盖第 1–4 个自然日（`ROUND_MAX = 3`），每块最多 2 个变体。第 5 天起不再产生新变化——这是明确接受的内容边界。任何"要不要多撑几天"的讨论推迟到 Phase 2，且必须先回答"多出来的天数用什么维度承载"。

### Phase 2：机制层

重复条目、多份互不印证记录、偏执回路对照物、第二幕全部文本。

（跨会话门已从本节移入 Phase 1 —— 它是切片成立的前提，不是后续增强：没有它，切片里唯一的变化就只有定稿那一次，玩家第二天回来什么也没发生。）

**进入条件：Phase 1 的机器门与真人通过门双双达标。** 未达标时不扩建内容，先修感知。

### Phase 3：叙事整合

白昼馆事件（第三幕）、签收单与推送（第四幕）、程露线、最终选择（第五幕）、隐藏选项系统。

### Phase 4：节奏与真人测试

沉默节奏表落地、不可逆丧失清单逐条验证、**玩家写入被接管**（见 4.8 降级说明）、性能调优（回显要快）、内容删减（Phase 4 的主要工作是删）。
